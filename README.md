# 0Lejit0 Overlays

Stream overlay pack for 0Lejit0: dark purple + teal, circle-L logo.

- `twitch/` 1920×1080 scenes (Starting Soon, BRB, Ending, Just Chatting, Gameplay, chat box with emotes &amp; badges)
- `tiktok/` 1080×1920 scenes
- `streamelements/` custom alert widget (HTML / CSS / JS / fields) with per-alert accents, messages, and timer bar
- `shared/` theme, logo and `config.js` (handles, banner timing, chat &amp; scene copy)
- `preview.html` local browser previewer, alert emulator &amp; OBS URL builder
- `previews/` screenshots of every scene

**Setup instructions: [SETUP.md](SETUP.md)**

To download: green **Code** button → **Download ZIP**.

`tools/` holds the page generator (`python3 tools/gen.py .`) and preview/timing scripts (Playwright).
